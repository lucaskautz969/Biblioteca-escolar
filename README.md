# Sistema de Biblioteca Escolar

Aplicação web local para cadastro de livros e exemplares, circulação por turma, histórico e inventário.

## Requisitos

- Windows, para utilizar os inicializadores `.bat`.
- Python na versão validada pelo desenvolvedor.
- Navegador atualizado.

Versão do Python utilizada: [3.13.7]

Aplicação web local para cadastro de livros e exemplares, circulação por turma, histórico e inventário.

## Requisitos

- Windows, para utilizar os inicializadores `.bat`.
- Python na versão validada pelo desenvolvedor.
- Navegador atualizado.

Versão do Python utilizada: [3.13.7]

## Instalação

Na pasta do projeto:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe init_db.py
```

## Execução

```powershell
.\iniciar_biblioteca.bat
```

Acessar:

http://127.0.0.1:8080

Para encerrar, pressionar `Ctrl + C` na janela do servidor.

## Dados

O repositório não inclui o banco utilizado pela escola, capas cadastradas, credenciais ou backups.

O banco local é preparado pelo `init_db.py`.

## Documentação

O manual do usuário está na pasta `docs`.

## Limitações

Uso local, sem autenticação e sem cadastro individual de estudantes.]
